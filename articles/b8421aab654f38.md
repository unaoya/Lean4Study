# この記事について

この記事の目的は、LEANを使って数学の定理を証明する、あるいは証明を検証するとはどういうことなのかについて簡単な例を通して紹介することです。

実際にLEANで数学の定理を証明する際には、tacticと呼ばれる方法を用いて証明を記述することが主です。しかし、どう証明を書くのかではなくなぜ証明が書けるのかに焦点を当てるため、この記事ではtacticを使わず証明を記述します。

# 項と型
LEANで扱う基本的な対象は項と呼ばれるもので、各々の項は型を持ちます。1や2は項でそれぞれ自然数型を持ちます。trueやfalseも項でBool型を持ちます。

1+1やture or falseなども項で、fun (x : Nat) => x + 1も項です。
x : Aと書いた時、項xが型Aを持つと読みます。

項と型は排他的ではなく、NatやBoolも項であり、これらはType型を持ちます。

# 実際に証明してみる

ここでは、「任意の自然数xについて、x * 1 = xである」という命題を証明することを考えます。

普通に数学の証明を書いてみます。といっても何を証明していいのかという感じですが、前提として自然数は0からで、自然数の掛け算は以下のように定義されているとします。

x * 0 = 0
x * (n + 1) = x * n + x

この定義を用いると、左辺はx * 1 = x * 0 + x = 0 + xと変形することができます。

次に自然数の足し算の定義は、

x + 0 = x
x + (n + 1) = (x + n) + 1

であるので、0 + x = xは定義そのものではなく証明が必要ですが、今回は話を簡単にするため、このことはすでに証明されているとして利用しましょう。以上で証明は完了します。
